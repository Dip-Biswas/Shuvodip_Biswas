# Shuvodip Biswas — Portfolio

Cybersecurity and machine learning portfolio, hosted at https://dip-biswas.github.io/Shuvodip_Biswas/.

GitHub Pages serves the repository root from `main`. `index.html` contains the complete design and packet-filter simulation. `Shuvodip_Biswas_CV_Classic.pdf` is the CV downloaded by the Save CV (PDF) link. Keep that file next to the HTML when publishing elsewhere.

The page has no build dependencies. `.nojekyll` lets Pages serve the static files directly.
